Ahí está el material completo — el recorrido de cada clase, las diapositivas, la

## Cómo usarlo

Cada clase del sitio tiene un badge que abre la notebook directo en Colab. También podés
descargar el `.ipynb` desde la página de la clase y correrlo local en Jupyter o RStudio.

Las notebooks vienen en dos versiones equivalentes, **Python** y **R**: recorren los
mismos pasos y llegan a las mismas conclusiones. Elegí la que prefieras.
